# Pixel Sorter

A small experiment with pixel sorting and basic image processing.

I originally started this because I wanted to understand how
image manipulation works instead of relying completely on
existing tools.

## Features

- Basic pixel sorting
- Horizontal and vertical sorting
- Adjustable threshold
- JPEG and PNG input
- Simple command-line interface

## Requirements

- Python 3.x
- Pillow

## Installation

```bash
pip install -r requirements.txt
